# Teman Jalan

**Every journey home deserves peace of mind.**

Teman Jalan is an inclusive community walking platform designed to make walking safer, more accessible, and more connected.

### Key Features
- **Safe Routes:** Walking routes informed by reported hazards and accessibility information.
- **Hazard Reporting:** Report broken streetlights, damaged pavements, and unsafe crossings.
- **Community:** Find walking buddies, join walking clubs, and organise group walks.
- **Accessibility:** Support for wheelchair-friendly routes and audio navigation.
- **Community Dashboard:** Help local authorities track hazards and prioritise repairs.
